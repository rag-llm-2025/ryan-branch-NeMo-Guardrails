# Guardrail对比演示应用 - 使用指南

## 🚀 快速开始

### 1. 安装依赖
```bash
pip install -r requirements.txt
```

### 2. 运行测试
```bash
python quick_test.py
```

### 3. 启动应用
```bash
python start_simple.py
```

### 4. 访问应用
打开浏览器访问: http://localhost:8501

## 📖 详细使用说明

### 应用界面

应用包含以下主要区域：

1. **标题栏**: 显示应用名称和图标
2. **侧边栏**: 配置选项
3. **主界面**: 
   - 输入框：输入您的问题
   - 示例查询选择器
   - 三个主要按钮
   - 结果显示区域

### 功能按钮

#### 🚫 无Guardrail模式
- **功能**: 直接调用GPT模型，不进行安全过滤
- **用途**: 对比原始GPT响应
- **显示**: 响应内容、延迟时间

#### 🛡️ 有Guardrail模式
- **功能**: 先进行安全检测，再生成响应
- **步骤**: 
  1. 安全检测（显示安全评级和类别）
  2. 根据检测结果生成响应
- **显示**: 安全检测结果、响应内容、分阶段延迟

#### ⚖️ 对比模式
- **功能**: 并排显示两种模式的结果
- **内容**: 
  - 输入对比
  - 响应对比
  - 延迟对比
  - 响应长度对比
  - 安全分析

### 性能指标

应用会显示以下性能指标：

1. **延迟时间**:
   - Guardrail延迟：安全检测耗时
   - GPT延迟：模型响应耗时
   - 总延迟：完整流程耗时

2. **响应长度**: 字符数统计

3. **安全评级**: 
   - 🟢 safe：安全内容
   - 🔴 unsafe：不安全内容

### 使用技巧

1. **对比测试**: 先用无Guardrail模式，再用有Guardrail模式，最后使用对比模式查看差异

2. **敏感内容测试**: 使用提供的敏感查询来测试Guardrail的过滤效果

3. **性能观察**: 注意观察两种模式的延迟差异

4. **响应质量**: 比较两种模式下的响应质量和内容安全性

### 故障排除

#### 常见问题

1. **应用无法启动**
   - 检查Python版本（建议3.8+）
   - 确认依赖已安装：`pip install -r requirements.txt`
   - 运行测试脚本：`python quick_test.py`

2. **API调用失败**
   - 检查网络连接
   - 确认API密钥有效
   - 检查Guardrail服务器是否运行

3. **响应缓慢**
   - 检查网络连接
   - 确认API服务状态
   - 考虑使用更简单的查询

#### 错误信息

- **"未设置OpenAI API密钥"**: 设置环境变量或使用默认密钥
- **"Guardrail API请求失败"**: 检查Guardrail服务器状态
- **"解析安全信息失败"**: 检查API响应格式

## 🔧 技术细节

### 架构说明

1. **前端**: Streamlit Web界面
2. **后端**: Python + 现有模块
3. **AI模型**: GPT-4o (Azure OpenAI)
4. **安全检测**: 自定义Guardrail API
5. **流式输出**: 实时响应生成

### 文件说明

- `streamlit_app.py`: 主应用文件
- `api_client.py`: API客户端
- `generate_prompt.py`: 提示词生成
- `gpt_4o_wrapper.py`: GPT-4o包装器
- `config.py`: 配置文件
- `quick_test.py`: 快速测试脚本
- `start_simple.py`: 简化启动脚本

### API接口

- **Guardrail API**: `http://localhost:8010/generate`
- **OpenAI API**: Azure OpenAI GPT-4o
- **Streamlit**: `http://localhost:8501`
